# Rohith Indupalli - Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript featuring dark/light mode toggle, smooth animations, and beautiful design.

## ✨ Features

- **🎨 Beautiful Color Palette**: Modern gradient design with purple, indigo, and pink accents
- **🌓 Dark/Light Mode**: Toggle between dark and light themes with smooth transitions
- **📱 Fully Responsive**: Optimized for all devices - desktop, tablet, and mobile
- **🎭 Smooth Animations**: Scroll-triggered animations and interactive effects
- **⚡ Performance Optimized**: Fast loading and smooth scrolling experience
- **🎯 Modern UI/UX**: Clean, intuitive interface with excellent user experience

## 🚀 Sections

1. **Hero Section** - Eye-catching introduction with animated gradient orbs
2. **About** - Personal introduction with animated statistics
3. **Education** - Timeline-based education history
4. **Skills** - Categorized skills with interactive tags
5. **Projects** - Featured projects with links and descriptions
6. **Certifications** - Professional certifications and achievements
7. **Footer** - Contact information and social links

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS variables, Grid, and Flexbox
- **JavaScript (ES6+)** - Interactive functionality
- **Font Awesome** - Icons for social links and UI elements

## 📦 Installation & Usage

1. **Clone or Download** the repository
   ```bash
   git clone https://github.com/RohithIndupalli/portfolio.git
   ```

2. **Open the project**
   - Simply open `index.html` in your web browser
   - Or use a local server (recommended):
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx serve
     ```

3. **View the website**
   - Open your browser and navigate to `http://localhost:8000`

## 🎨 Customization

### Changing Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --accent-primary: #6366f1;
    --accent-secondary: #8b5cf6;
    --accent-tertiary: #ec4899;
    /* Add your custom colors */
}
```

### Adding Content

- **Projects**: Add new project items in the `#projects` section of `index.html`
- **Skills**: Update the skills grid in the `#skills` section
- **Education**: Add timeline items in the `#education` section

## 🌟 Key Features Explained

### Dark/Light Mode
- Automatically saves user preference in localStorage
- Smooth transition between themes
- Custom color schemes for both modes

### Scroll Animations
- Intersection Observer API for performance
- Staggered animations for visual appeal
- Parallax effects on hero section

### Responsive Design
- Mobile-first approach
- Hamburger menu for mobile devices
- Flexible grid layouts
